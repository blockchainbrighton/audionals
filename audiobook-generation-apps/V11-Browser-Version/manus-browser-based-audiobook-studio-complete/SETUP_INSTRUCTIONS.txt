## ⏱️ 1. Quick Start (5 Minutes)

### Prerequisites

* **Docker & Docker Compose** installed.
* **RAM:** 8GB minimum available.
* **Storage:** 50GB free disk space.

### Installation Steps

1. **Extract Archive**
```bash
unzip audiobook-studio-complete.zip
cd audiobook-studio-complete

```


2. **Configure Environment**
```bash
cp .env.example .env

```


3. **Start Services**
*Option A: Helper Script*
```bash
./scripts/quickstart.sh start

```


*Option B: Docker Compose*
```bash
docker-compose up -d

```


4. **Initialize**
Wait 30-60 seconds for all containers to initialize.
5. **Launch**
Open your browser to `http://localhost:5173` and start creating!

## ⚙️ 5. Configuration

Edit the `.env` file to customize your setup.

### Basic Settings

```bash
VITE_API_URL=http://localhost:3000
VITE_WS_URL=ws://localhost:3000
NODE_ENV=production
TTS_SERVICE_URL=http://tts-engine:5000
TTS_FALLBACK_ENABLED=true
DATABASE_URL=sqlite:///./data/audiobook_studio.db
REDIS_URL=redis://redis:6379

```

### GPU Acceleration (Recommended)

To enable CUDA support for faster generation:

1. **Edit `.env`:**
```bash
TTS_DEVICE=cuda
TTS_GPU_MEMORY_FRACTION=0.8

```


2. **Restart Engine:**
```bash
docker-compose restart tts-engine

```

## 🔧 7. Troubleshooting

### Services won't start

```bash
docker-compose logs
docker-compose down
docker-compose up -d --build

```

### Out of Memory

```bash
docker stats
# Edit .env to use smaller model:
# TTS_MODEL=tts_models/en/ljspeech/glow-tts
docker-compose restart tts-engine

```

### GPU not being used

```bash
nvidia-smi
docker-compose exec tts-engine python -c "import torch; print(torch.cuda.is_available())"
# Ensure TTS_DEVICE=cuda in .env

```

### Port Conflicts

```bash
lsof -i :3000
lsof -i :5000
lsof -i :5173
# kill -9 <PID>

```
