# Installation Guide - Audiobook Studio\n\n## Table of Contents\n\n1. [Docker Installation (Recommended)](#docker-installation)\n2. [Local Installation](#local-installation)\n3. [Troubleshooting](#troubleshooting)\n\n---\n\n## Docker Installation (Recommended)\n\n### Prerequisites\n\n- **Docker Desktop** (Windows/macOS) or **Docker Engine** (Linux)\n- **Docker Compose** (usually included with Docker Desktop)\n- 8GB RAM minimum\n- 50GB free disk space\n- Internet connection\n\n### Step 1: Install Docker\n\n**Windows/macOS:**\n1. Download [Docker Desktop](https://www.docker.com/products/docker-desktop)\n2. Install and launch\n3. Verify: `docker --version`\n\n**Linux (Ubuntu/Debian):**\n```bash\nsudo apt-get update\nsudo apt-get install -y docker.io docker-compose\nsudo usermod -aG docker $USER\nnewgrp docker\n```\n\n### Step 2: Clone Repository\n\n```bash\ngit clone https://github.com/yourusername/audiobook-studio.git\ncd audiobook-studio\n```\n\n### Step 3: Configure Environment\n\n```bash\n# Copy example environment file\ncp .env.example .env\n\n# Edit .env if needed (optional - defaults work for local development)\nvim .env\n```\n\n### Step 4: Start Services\n\n```bash\n# Build and start all services\ndocker-compose up -d\n\n# Watch logs\ndocker-compose logs -f\n```\n\n### Step 5: Verify Installation\n\n```bash\n# Check all services are running\ndocker-compose ps\n\n# Test backend health\ncurl http://localhost:3000/health\n\n# Test TTS engine\ncurl http://localhost:5000/health\n```\n\n### Step 6: Access Application\n\n- **Frontend:** http://localhost:5173\n- **Backend API:** http://localhost:3000\n- **TTS Engine:** http://localhost:5000\n- **Redis:** localhost:6379\n\n---\n\n## Local Installation\n\n### Prerequisites\n\n- **Node.js** 18+ ([Download](https://nodejs.org/))\n- **Python** 3.9+ ([Download](https://www.python.org/))\n- **FFmpeg** ([Download](https://ffmpeg.org/download.html))\n- **Git** ([Download](https://git-scm.com/))\n- **Redis** (optional, for job queue)\n\n### Step 1: Install Dependencies\n\n**Windows:**\n```batch\n# Install Chocolatey (if not installed)\n@\"%SystemRoot%\\System32\\cmd.exe\" /c \"powershell -NoProfile -InputFormat None -ExecutionPolicy Bypass -Command \"[System.Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))\" && SET \"PATH=%PATH%;%ALLUSERSPROFILE%\\chocolatey\\bin\"\n\n# Install dependencies\nchoco install python nodejs ffmpeg git -y\n```\n\n**macOS:**\n```bash\n# Install Homebrew (if not installed)\n/bin/bash -c \"$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)\"\n\n# Install dependencies\nbrew install python node ffmpeg git redis\n```\n\n**Linux (Ubuntu/Debian):**\n```bash\nsudo apt-get update\nsudo apt-get install -y python3 python3-pip python3-dev nodejs npm ffmpeg git build-essential redis-server\n```\n\n### Step 2: Clone Repository\n\n```bash\ngit clone https://github.com/yourusername/audiobook-studio.git\ncd audiobook-studio\n```\n\n### Step 3: Setup Frontend\n\n```bash\ncd frontend\n\n# Install dependencies\nnpm install\n\n# Start development server\nnpm run dev\n\n# In another terminal, continue with backend setup\n```\n\n### Step 4: Setup Backend\n\n```bash\ncd backend\n\n# Install dependencies\nnpm install\n\n# Create data directory\nmkdir -p data/uploads\n\n# Start backend server\nnpm run dev\n\n# In another terminal, continue with TTS setup\n```\n\n### Step 5: Setup TTS Engine\n\n```bash\ncd tts-engine\n\n# Create virtual environment\npython3 -m venv venv\n\n# Activate virtual environment\n# Windows:\nvenv\\Scripts\\activate\n# macOS/Linux:\nsource venv/bin/activate\n\n# Install dependencies\npip install --upgrade pip\npip install -r requirements.txt\n\n# Download TTS model (first run only)\npython -c \"from TTS.api import TTS; TTS(model_name='tts_models/en/ljspeech/glow-tts')\"\n\n# Start TTS engine\npython app.py\n```\n\n### Step 6: Start Redis (Optional but Recommended)\n\n**Windows:**\n```batch\n# Redis Windows port\nredis-server\n```\n\n**macOS:**\n```bash\nredis-server\n```\n\n**Linux:**\n```bash\nsudo systemctl start redis-server\n```\n\n### Step 7: Access Application\n\nOpen browser to http://localhost:5173\n\n---\n\n## GPU Setup\n\n### NVIDIA GPU (CUDA)\n\n#### 1. Install NVIDIA Drivers\n\n**Windows:**\n- Download from [NVIDIA Driver Downloads](https://www.nvidia.com/Download/driverDetails.aspx)\n- Install and restart\n\n**macOS:**\n- Not supported (use Metal Performance Shaders instead)\n\n**Linux:**\n```bash\nsudo apt-get install nvidia-driver-525\nsudo reboot\n```\n\n#### 2. Install CUDA Toolkit\n\n```bash\n# Download from https://developer.nvidia.com/cuda-downloads\n# Follow installation instructions for your OS\n\n# Verify installation\nnvcc --version\nnvidia-smi\n```\n\n#### 3. Install cuDNN\n\n```bash\n# Download from https://developer.nvidia.com/cudnn\n# Extract and copy to CUDA installation directory\n```\n\n#### 4. Install PyTorch with CUDA Support\n\n```bash\ncd tts-engine\nsource venv/bin/activate\n\npip uninstall torch torchvision torchaudio\npip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118\n\n# Verify\npython -c \"import torch; print(torch.cuda.is_available())\"\n```\n\n#### 5. Update Environment\n\n```bash\n# Edit .env\nTTS_DEVICE=cuda\nTTS_GPU_MEMORY_FRACTION=0.8\n\n# Restart TTS engine\npython app.py\n```\n\n### AMD GPU (ROCm)\n\n```bash\n# Install ROCm\n# https://rocmdocs.amd.com/en/latest/deploy/linux/index.html\n\n# Install PyTorch with ROCm\npip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm5.7\n\n# Update .env\nTTS_DEVICE=cuda  # ROCm is compatible with CUDA API\n```\n\n### macOS (Metal Performance Shaders)\n\n```bash\n# Install PyTorch with Metal support\npip install torch torchvision torchaudio\n\n# Update .env\nTTS_DEVICE=mps\n```\n\n---\n\n## Verification\n\n### Check Services\n\n```bash\n# Docker\ndocker-compose ps\n\n# Backend health\ncurl http://localhost:3000/health\n\n# TTS health\ncurl http://localhost:5000/health\n\n# Redis\nredis-cli ping\n```\n\n### Test Generation\n\n```bash\n# Test TTS generation\ncurl -X POST http://localhost:5000/generate \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"text\": \"Hello world\"}' \\\n  --output test.wav\n\n# Play audio\nffplay test.wav\n```\n\n### View Logs\n\n```bash\n# Docker\ndocker-compose logs -f backend\ndocker-compose logs -f tts-engine\n\n# Local\n# Check backend/logs/ and tts-engine/logs/\n```\n\n---\n\n## Troubleshooting\n\n### Port Already in Use\n\n```bash\n# Find process using port\nlsof -i :3000\nlsof -i :5000\nlsof -i :5173\n\n# Kill process\nkill -9 <PID>\n\n# Or change port in .env\nPORT=3001\n```\n\n### Out of Memory\n\n```bash\n# Check memory usage\nfree -h  # Linux\nvm_stat  # macOS\n\n# Use smaller TTS model\nTTS_MODEL=tts_models/en/ljspeech/glow-tts\n\n# Reduce batch size\nBATCH_SIZE=1\n```\n\n### GPU Not Detected\n\n```bash\n# Check drivers\nnvidia-smi\n\n# Check PyTorch\npython -c \"import torch; print(torch.cuda.is_available())\"\n\n# Reinstall PyTorch\npip uninstall torch\npip install torch --index-url https://download.pytorch.org/whl/cu118\n```\n\n### Services Won't Start\n\n```bash\n# Check logs\ndocker-compose logs\n\n# Rebuild\ndocker-compose down\ndocker-compose up -d --build\n\n# Or locally\nnpm run dev  # Check for errors\n```\n\nSee [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for more solutions.\n\n---\n\n**Next Steps:**\n- Read [USER_GUIDE.md](USER_GUIDE.md) for usage instructions\n- Check [DOCKER_GUIDE.md](DOCKER_GUIDE.md) for Docker operations\n- Review [API_REFERENCE.md](API_REFERENCE.md) for API documentation\n
