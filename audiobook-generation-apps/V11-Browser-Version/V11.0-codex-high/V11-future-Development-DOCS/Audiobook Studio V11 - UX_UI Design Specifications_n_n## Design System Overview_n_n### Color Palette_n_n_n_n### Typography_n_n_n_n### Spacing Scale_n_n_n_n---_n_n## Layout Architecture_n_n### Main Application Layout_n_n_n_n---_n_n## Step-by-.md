# Audiobook Studio V11 - UX/UI Design Specifications\n\n## Design System Overview\n\n### Color Palette\n\n```\nPrimary Colors:\n  - Primary Blue: #3B82F6 (action buttons, links)\n  - Success Green: #10B981 (completion, success states)\n  - Warning Orange: #F59E0B (processing, warnings)\n  - Danger Red: #EF4444 (errors, destructive actions)\n  - Neutral Gray: #6B7280 (secondary text, disabled states)\n\nBackground Colors:\n  - Dark Background: #0F172A (main background)\n  - Card Background: #1E293B (panels, cards)\n  - Input Background: #334155 (form inputs)\n  - Hover State: #475569 (interactive hover)\n\nText Colors:\n  - Primary Text: #F1F5F9 (main text)\n  - Secondary Text: #CBD5E1 (secondary text)\n  - Muted Text: #94A3B8 (disabled, muted)\n```\n\n### Typography\n\n```\nFont Stack: Inter, system-ui, -apple-system, sans-serif\n\nHeadings:\n  - H1: 32px, 700 weight, 1.2 line-height\n  - H2: 24px, 600 weight, 1.3 line-height\n  - H3: 18px, 600 weight, 1.4 line-height\n  - H4: 16px, 600 weight, 1.4 line-height\n\nBody:\n  - Regular: 14px, 400 weight, 1.5 line-height\n  - Small: 12px, 400 weight, 1.5 line-height\n  - Mono: Fira Code, 12px (for code/logs)\n```\n\n### All features accessible\n\nTablet (768px - 1199px)\n├─ Collapsible sidebar\n├─ Stacked 2-column layouts\n├─ Simplified toolbar\n└─ Touch-friendly buttons (48px min)\n\nMobile (< 768px)\n├─ Full-width layout\n├─ Bottom navigation\n├─ Single column\n├─ Large touch targets (56px min)\n└─ Simplified UI\n```\n\n---\n\n## Accessibility Guidelines\n\n### WCAG 2.1 AA Compliance\n\n- ✅ Color contrast ratio ≥ 4.5:1 for text\n- ✅ All interactive elements keyboard accessible\n- ✅ ARIA labels for screen readers\n- ✅ Focus indicators visible (min 2px)\n- ✅ Form labels associated with inputs\n- ✅ Error messages descriptive and linked to inputs\n- ✅ Motion/animations can be disabled\n- ✅ Text resizable up to 200%\n\n### Keyboard Navigation\n\n```\nTab        → Move to next element\nShift+Tab  → Move to previous element\nEnter      → Activate button/link\nSpace      → Toggle checkbox/radio\nArrow Keys → Navigate within components\nEsc        → Close dialogs/menus\nCtrl+S     → Save project\nCtrl+Z     → Undo\nCtrl+Y     → Redo\n```\n\n---\n\n## Animation & Transitions\n\n```\nStandard Transitions:\n- Fade: 200ms ease-in-out\n- Slide: 300ms ease-out\n- Scale: 150ms ease-out\n\nProgress Animations:\n- Progress bar: smooth continuous\n- Status changes: 300ms fade\n- Loading spinner: 1s rotation\n\nInteractive Feedback:\n- Button hover: 150ms scale(1.05)\n- Button press: 100ms scale(0.95)\n- Input focus: 200ms border color change\n```\n\n---\n\n## Error & Success States\n\n### Error Message\n```\n⚠️ Generation Failed\nCould not generate audio for Chapter 2.\n[Retry]
