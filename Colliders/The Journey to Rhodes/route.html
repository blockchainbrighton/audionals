The Antikythera Route

Mapping the hypothetical journey from Rome to Rhodes (c. 67 BC), plus a colour-coded return journey showing the intended course, drift toward Antikythera, and the final lightning-to-sinking segment.

Start: Port of Ostia (Rome)
Destination: Rhodes
Wreck Site: Antikythera

Route Segments:

Outbound route (reconstructed)
Return (intended)
Return (blown off course toward Antikythera)
Lightning → sinking
  • Outbound: south via Strait of Messina → Ionian → W. Greece → Antikythera → N. Crete → Rhodes
  • Return: intended to run south of Antikythera (yellow), but weather drives the ship up toward the island (orange)
  • Lightning strike triggers the final short sinking segment (red)
Historical Note:
While this map visualizes a Rome → Rhodes journey, many historians argue the ship may have been traveling East → West, carrying high-value cargo toward Italy when it sank.
